# Array Exercises

Six topics, in order — each one builds on the last:

1. [01-creating-arrays](01-creating-arrays) — array literals, indexing, `.length`
2. [02-modifying-arrays](02-modifying-arrays) — changing items, `push`/`pop`/`shift`/`unshift`
3. [03-looping-arrays](03-looping-arrays) — `for`, building sums/strings/new arrays by hand
4. [04-searching-arrays](04-searching-arrays) — `includes`, `indexOf`, `find`
5. [05-transforming-arrays](05-transforming-arrays) — `map`, `filter`
6. [06-sorting-and-combining](06-sorting-and-combining) — `sort`, `reverse`, `slice`

## Each topic folder has 2 files

- **`exercise.js`** — functions to finish. Every spot to edit is marked:
  ```js
  // TODO: your code here
  ```
  Run it directly to manually check your work:
  ```
  node exercises/01-creating-arrays/exercise.js
  ```
- **`exercise.test.js`** — the tests that score `exercise.js`. Run just this
  topic's tests:
  ```
  npx jest exercises/01-creating-arrays
  ```
  Or run everything:
  ```
  npm test
  ```

npm install
