# learn-js

A hands-on, one-topic-per-branch way to learn JavaScript data types. Each branch
covers a single topic with short lessons, runnable examples, and exercises
scored by tests.

This branch (`mats/array-basics`) covers **Arrays**.

## Prerequisites

You should already be comfortable with:
- Primitive/basic data types (numbers, strings, booleans)
- Declaring variables (`let`, `const`)
- Basic math operators (`+ - * / %`) and comparison/logical operators (`=== < > && ||`)

Arrays are new — that's what this branch teaches.

## Setup

```
npm install
```

## How each lesson works

Go to [`arrays/README.md`](arrays/README.md) for the full lesson list and how
to run examples/exercises with `node` and score them with `jest`.

## Working on your own copy

Fork or clone this repo, then create your own branch (e.g. `you/array-basics`)
and work through the exercises there. Every exercise file has `TODO` markers
showing exactly what to fill in — leave the rest of the file untouched so the
tests keep working.
